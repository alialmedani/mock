# ERP App Mockup

An interactive design mockup. All names and figures are sample data, and nothing is sent to a server. Your settings and progress are saved only in your own browser; use **Reset the demo** on the Me screen to start fresh.

## What's new
- The design matches the app's colors, fonts, cards, forms and report screens, in light and dark mode.
- Home is built from the modules the user has: KPIs (1 for one module, up to 3 for more), up to 4 shortcuts and a module grid, ordered by what the user opens most. Shortcuts the user edits are kept.
- Turn modules on or off in the preview panel; "Home for this access" explains which rule produced each part of Home.
- Attendance only: the bar shows Home, Attendance Record, Leaves and Profile, and Home has the app's attendance card (live clock and fingerprint button).
- Attendance with other modules: the center button of the bar is the fingerprint for checking in, and an Attendance tab opens Attendance Records and Leaves in two tabs.
- With many modules, the module button in the bar opens that module directly; tap it again to switch modules. In Profile, "Modules in the bar" lets each user choose which module(s) the bar shows (1 with Attendance, up to 2 without).
- The Smart Attendance screen is only for recording: Check In, Surprise Attendance and Check Out.
- Approvals open a review screen with Approve and Reject; there is no quick approve in lists.
- The bell shows notifications only. "Waiting for you", "Continue where you left off" and the pin buttons on screens were removed.
- Hold an icon to rearrange it (home grid, pinned items, module screens and the Modules page), like on iPhone.
- The browser remembers your user type, language, theme, modules, shortcuts, order and check-in after a reload.
- Added HR forms (shifts, swaps, schedules, leave balances), a POS rep picker, held sales and returns, and Kurdish text.

## View it
Open `index.html` in a browser.

## Publish it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Open the address GitHub shows after a minute or two.

GitHub Pages sites are public on the free plan, even when the repository is private on some plans. Anyone with the address can view this mockup.
