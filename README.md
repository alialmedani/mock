# ERP App Mockup

An interactive design mockup. All names and figures are sample data, and nothing is saved or sent to a server.

## View it
Open `index.html` in a browser.

## Publish it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Open the address GitHub shows after a minute or two.

GitHub Pages sites are public on the free plan, even when the repository is private on some plans. Anyone with the address can view this mockup.
