# ERP App Mockup

An interactive design mockup. All names and figures are sample data, and nothing is sent to a server. Your settings and progress are saved only in your own browser; use **Reset the demo** on the Me screen to start fresh.

## What's new
- The design follows the app's colors, fonts and tokens in light and dark mode: one spacing, radius, shadow and type scale, module accent colors on every icon, press feedback, skeleton loading and empty states.
- Home has a Highlights carousel for company news, employee of the month, congratulations and events. Cards can be dismissed or marked as read, expired items disappear, and the section hides when there is nothing to show. Numeric KPI cards were removed.
- Home is built from the modules the user has: up to 4 shortcuts (Pinned) and a module grid, ordered by what the user opens most. Shortcuts the user edits are kept.
- Turn modules on or off in the preview panel; "Home for this access" explains which rule produced each part of Home. The "Highlights" control shows every state: none, one, several, each template and edge cases.
- Module screens have a clean header (module icon, name and quick actions) with no statistics, document tiles with record counts, and recent documents.
- Attendance only: the bar shows Home, Attendance Record, Leaves and Profile, and Home has the app's attendance card (live clock and fingerprint button).
- Attendance with other modules: the center button is the fingerprint for checking in. Its icon is amber before check-in and green after, with a slow pulse. An Attendance tab opens Attendance Records and Leaves.
- Attendance Record shows a weekly summary, worked time and an on-time, late or early-leave status for each day.
- The module button in the bar opens that module; hold it to switch modules. In Profile, "Modules in the bar" lets each user choose which module(s) the bar shows.
- Document lists have a "New" button in the title bar. Approvals open a review screen with Approve and Reject.
- The bell shows notifications only. Profile has a separate Log out button and an avatar with a photo or initials.
- "Icon colors" in the preview panel switches between module colors and the app's primary color for comparison; it starts on module colors every time.
- Hold an icon to rearrange it (home grid, pinned items, module screens and the Modules page), like on iPhone.
- The browser remembers your user type, language, theme, modules, shortcuts, order, check-in and dismissed highlights after a reload.

## View it
Open `index.html` in a browser.

## Publish it on GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `.nojekyll` and this `README.md` to the repository root.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Open the address GitHub shows after a minute or two.

GitHub Pages sites are public on the free plan, even when the repository is private on some plans. Anyone with the address can view this mockup.
